# Мои платежи (PaymentTracker)

Android-приложение (Kotlin): считает рассрочку/кредит.
Вводите общую сумму, остаток, платёж в месяц и день оплаты — приложение показывает
сколько оплачено, сколько осталось, сколько месяцев, дату следующего платежа и дату закрытия.

## Сборка
- Android Studio: открыть папку и нажать Run.
- Через GitHub: push в ветку main → вкладка Actions → артефакт app-debug (APK).
