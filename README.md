# Мой дом (PaymentTracker)

Android-приложение (Kotlin) для учёта выплат за жильё.
Чем больше оплачено, тем выше «построен» дом на фоне (0% — стройплощадка с краном, 100% — готовый комплекс).

- Настройки (⚙): общая сумма, валюта (UZS, USD, EUR, RUB, KZT, TRY, GBP), первый взнос, день оплаты.
- Каждый платёж вводится отдельно — суммы могут быть разными.
- Показывает остаток, процент, дату следующего платежа и прогноз срока.

## Сборка
- Android Studio: открыть папку и Run.
- GitHub: push в main → вкладка Actions → артефакт app-debug (APK).
